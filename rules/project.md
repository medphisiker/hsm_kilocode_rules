# Project Rules: HSM

Эти правила специфичны для проекта Hyper Stack Manager (HSM).

## 🎯 Цель
Мета-оркестратор для гибридных стеков (Python + Docker).

## 📋 Архитектурные принципы
- **Meta-Orchestration**: HSM не заменяет инструменты, а управляет ими.
- **Atomic Sync**: Все изменения в конфигах проекта должны быть транзакционными.
- **Round-Trip YAML**: Сохранение комментариев пользователя в манифестах.

## 🛠️ Стек
- Python 3.13+ (uv).
- Docker SDK.
- PyYAML для работы с манифестами.

## 🌍 Кроссплатформенность
- **Стандарт**: Все операции с файловой системой (создание, удаление, перемещение директорий и файлов) должны выполняться исключительно через стандартные библиотеки Python: `pathlib` и `shutil`.
- **Запрет**: Прямое использование системных команд (`rm`, `mkdir`, `cp`) через `os.system` или `subprocess` для управления структурой проекта.

## 🧪 Стратегия тестирования и отладки
- **Изоляция**: Каждый тест должен работать в уникальной временной директории.
- **Режим отладки**: При установленной переменной `HSM_DEBUG_TESTS=1` артефакты тестов сохраняются в директории `debug_tests/` в корне проекта.
- **Версионирование**: В режиме отладки для каждого запуска теста создается новая поддиректория `run_<N>`, что позволяет сравнивать результаты разных итераций.
