# Проектные правила (Project Specific) - HSM

## 🐍 Стандарты кодирования
- **Язык кода**: Английский.
- **Docstrings**: Google Style.
- **Версия Python**: 3.13+.

## 🏗️ Структура проекта
- **Build System**: `uv` (`uv_build`).
- `src/hyper_stack_manager/` — Исходный код.
- `docs/` — Техническая документация.
- `hsm-registry/` — Локальный реестр для тестов.

## 📋 Архитектурные принципы
- **Meta-Orchestration**: HSM не заменяет инструменты, а управляет ими.
- **Atomic Sync**: Все изменения в конфигах проекта должны быть транзакционными.
- **Round-Trip YAML**: Сохранение комментариев пользователя в манифестах.
