# Project Brief: Hyper Stack Manager (HSM)

## Vision
**HSM** — это Meta-Orchestrator для современной разработки, выступающий в роли "Environment Hypervisor". Он позволяет декларативно собирать рабочее окружение проекта из независимых компонентов (Python-пакетов и Docker-контейнеров) на основе единого манифеста.

## Ключевые возможности
- **Hybrid Stack Orchestration**: Единый манифест `hsm.yaml` для кода и инфраструктуры.
- **Virtual Components**: Легкая подмена реализаций интерфейсов (1-of-N).
- **Dependency Implication (Implies)**: Декларативная связь между кодом и инфраструктурой (например, выбор клиента БД автоматически настраивает нужный сервис).
- **Atomic Sync**: Транзакционная безопасность — ваши рабочие конфиги не сломаются при ошибке резолвинга.
- **Native Dev/Prod Bridge**: Автоматизация рутины по переходу от dev к prod окружению с локальным хранением режимов.

## Целевая аудитория
Разработчики сложных модульных систем, платформенные инженеры, команды, использующие микросервисную архитектуру.
